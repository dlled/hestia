# Ecosystem compatibility matrix

| Surface | Supported baseline | Compatibility rule |
| --- | --- | --- |
| Encore runtime | Encore.ts 1.58.x | `encore check`, generated client and portable image must pass before upgrades |
| MCP | 2026-07-28 only | Legacy negotiation is rejected; effectful flows require signed request state |
| TypeScript SDK | Generated by Encore 1.58.1 | Regenerate from the local graph and review the diff with every exposed API change |
| OpenAPI | Encore experimental generator | Public endpoints only; private service endpoints are excluded |
| Plugins | HESTIA Plugin API 1 | Strict manifest, no filesystem writes, no direct network, capability allowlist |
| MQTT | MQTT 5, QoS 1 | Canonical entity-state event, topic/body binding and signed webhook handoff |
| Webhooks | HMAC-SHA256 v1 | Five-minute freshness window and event-id replay protection |

Generated artifacts live in `sdk/`. Run `pnpm sdk:generate` after changing an exposed endpoint.
