# Product source

Phase 0 was generated from:

- `HESTIA_Documento_Requisitos_y_Arquitectura_v0.1`
- `HESTIA_Plan_Ejecutivo_v0.1`

Those documents are the product/architecture contract. This repo implements them incrementally.

## North star

A person expresses an intent. HESTIA understands context, proposes a visible plan, applies policy, executes durably, observes the result, and can explain or undo what happened.

## MVP vertical

“I'm going to sleep”: lights, climate, covers, media, and alarm as a typed plan with selective approval and observed-state verification. If the model is down, a published deterministic routine still runs.
